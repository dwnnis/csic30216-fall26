API Budget

Each student has an API budget of NT$1,000 for the semester. This covers API calls for assignments and labs. Use Haiku for experimentation and test runs; use Sonnet for graded submissions and production-quality work.

Budget distribution instructions and API key setup are posted separately on the course portal.

Office hours schedule posted on the course portal. For technical issues during lab weeks, TAs hold extended drop-in sessions — times posted on the schedule page for async weeks.
